# API Reference

The full OpenAPI contract is available at [specs/001-develop-git-rest/contracts/openapi.yaml](../specs/001-develop-git-rest/contracts/openapi.yaml).

## Endpoints

- `/repos` - List and clone repositories
- `/repos/{repo_id}` - Repository details and switching
- `/repos/{repo_id}/branches` - Branch management
- `/repos/{repo_id}/commit` - Commit changes
- `/repos/{repo_id}/diff` - View diffs
- `/repos/{repo_id}/files` - List files
- `/repos/{repo_id}/files/{file_path}` - Retrieve file contents

See the OpenAPI spec for request/response details.
